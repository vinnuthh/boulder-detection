Lunar Boulder Hazard

End-to-end demo: LROC NAC → YOLOv8n → GSD size estimate → 50 m hazard grid → static Leaflet viewer.

High-resolution lunar surface imagery is tiled into 512 px chips, run through the boulder detector, and each box is converted from pixels to metres using the GeoTIFF transform. Detections are binned into 50 m cells; each cell takes the worse of its maximum boulder size and boulder density class for the selected mission profile.

1 · Detect

YOLOv8n fine-tuned on synthetic LROC-like tiles with realistic boulders, craters, shadows and sensor noise.

2 · Measure

Diameter = longest box side × GSD. GSD comes from the local tile GeoTIFF transform (transform.a).

3 · Classify

Size and density thresholds per profile, combined worst-case. Both lander and rover grids are exported in one run.

4 · Explore

Confidence slider filters markers and recomputes the hazard grid in the browser. Profile toggle swaps thresholds instantly.

Model status: loading. The viewer records the detector actually used in hazard_meta.json; if PyTorch is unavailable, the pipeline falls back to a classical bright-body + cast-shadow detector so the demo still runs.

URL parameters: ?profile=rover&conf=0.5&opacity=0.7. Share a link to reproduce a view.

Caveat: boulder diameter is a 2-D bounding-box estimate; shadows and overlapping rocks can bias it. Hazard zones are decision support for a demo, not flight certification.
